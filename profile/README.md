# Lang3

An AI mixing assistant and plug-in controllers for Pro Tools.

## What we build

**Lang3 AI Mixing Assistant** — drives a Pro Tools session by text or voice: transport, editing, plug-in parameters, routing. It handles the operating work, not the mix decisions.

**L3EQ / L3DY** — hardware controllers for EQ and dynamics.

## Status

Pre-launch. The software is running; the controllers are at PCB design stage. Pro Tools first, on macOS (Apple Silicon and Intel).

## Free tools

- [Session Naming Check](https://lang3.co/tools/session-check/) — export Session Info as Text from Pro Tools, paste it in, get a report on naming inconsistencies. Runs in the browser, nothing uploaded.
- [Delay & Reverb Calculator](https://lang3.co/tools/bpm-calculator/) — time-based plug-in settings from tempo and vocal type.
